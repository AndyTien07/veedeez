# veedeez

my vd shit to evaluate the performance of motor powered baby driven unicycles.

Install MFEVAL, run the solver, then run one of the visualization options.

To disable the cool graphic change diagnostic to false

Validate tire model orientation using diagnostic window and the visualization script MFEVAL comes with 

Visualization tools:

Constant Radius-> filters vs and displays steer degrees vs Velocity. Set to skidpad by default. WILL NOT WORK IF VELOCITY STEPS TOO LARGE IN SOLVER

Constant Velocity-> shows all possible radii at velocity

YMD -> Yaw Moment Diagram for all velocities

Vis-> Basic Visualization, shows YMD and states at a given velocity as well as the highest steady state G of all velocities
